# JurisControl
<p align="center">
SaaS ERP Jurídico para gestão de escritórios de advocacia.
</p>

## Público Alvo

O sistema de gestão JurisControl é voltado para todo e qualquer escritório de advocacia, desde novos escritórios, advogados autônomos, a escritórios consolidados.

## Características do projeto

O sistema de gestão jurídico Juriscontrol foi criado para fazer a gestão completa de um escritório de advocacia.

- Gestão Administrativa;
    - Gestão de Clientes;
    - Gestão de Contratos;
    - Gestão de Usuários;
    - Gestão de Parceiros;
    - Gestão de Recursos Humanos e Departamento Pessoal;
- Gestão Financeira;
    - Faturas (contas a pagar e receber);
    - Pagamentos;
    - Honorários;
- Gestão Jurídica;
    - Processos;
